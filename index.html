01

访谈结论

基于三份初始访谈记录的整体判断。

本次对三位 UI 设计师的访谈，整体情况平稳。三位员工对现有工作状态、团队氛围与福利均给予正面反馈，没有出现需要立即介入的负面信号。

02

三位同事的访谈重点

每位同事提炼 3 个关键点。

张

张洁

二次入职满一年 · UI 设计

访谈关键点
#
关键点
说明
1
角色转变中的适应期
从「只对接产品做设计」到新增用户沟通职责，前期被打断思路会有情绪，目前已逐渐认同「用户沟通是职责的一部分」。
2
沟通语气与时效待改进
被反馈群内回复语气生硬，目前靠模仿同事的沟通方式改进；客户反馈回复慢的主因是信息过多没有及时看到。
3
内部协作存在分歧
与开发在需求取舍上常有观点冲突，僵持时请求上级出面解决；整体工作状态自评舒适，对薪资福利无意见。
魏

魏大龙

线上展览方向 · UI 设计

访谈关键点
#
关键点
说明
1
年度进步明显，已可独立承担线上展览设计任务
本年度专业能力提升显著，已具备独立负责线上展览设计任务的能力，且交付成果获得认可，工作压力整体可控。
2
与开发协同顺畅，新技术应用意愿强且有实际落地
在技术实现上与镜宇配合良好，能够主动根据开发建议学习新工具并落地应用，展现出较强的学习意愿与执行力。
3
对外汇报有心理门槛
线上沟通无压力，但担心未来独立做线下汇报「讲不好」，可接受在协助下逐步尝试。
巫

巫婷婷

接手 UI 工作大半年 · 项目主导

访谈关键点
#
关键点
说明
1
年度进步明显，跨部门沟通与外部汇报表现突出
本年度专业能力进步显著，特别是在跨部门沟通协作及外部工作汇报方面成果表现突出，可独立外出向客户进行工作汇报。
2
需求应对与冲突化解能力较强
面对用户需求反复调整的情况，能够先自行评估消化、重大变动及时上报决策；与开发沟通出现分歧时情绪稳定，善于借助用户反馈推动工作落地，不受负面情绪影响。
3
意愿尝试新任务，提升自身技能
明确表达愿意尝试线上展览等新类型项目，以拓展工作范围、提升自身技能；薪资福利方面满意度尚可，同时提出加薪期望。
03

访谈原始记录

以下为三位同事的初始访谈问答原文，按记录顺序完整保留，未作改写。

谭
访谈人

二次入职回来也满一年了，觉得现在的工作跟之前会有哪些变化呢？

张
张洁

最大的变化可能是多了较多设计外的杂事吧，之前不会有对外的沟通，只需要跟产品对接好再设计就行，现在的话会多了用户的沟通。因为会希望在设计的时候能沉浸在里面，经常会被打断了思路，就会有情绪。当然后面也会了解到用户沟通也是工作职责的一部分，觉得还是需要适应这样的工作状态的。

谭
访谈人

刚你有说到用户的沟通，你是怎么看待这块的工作呢，是会觉得比较反感吗？

张
张洁

现在的话没有的，开始的时候会比较紧张，不知道要怎么回复，和她们接触久了发现其实用户也是比较好说话的，就慢慢的不紧张了。但是敬和姐有说过我在群里回复的语气很生硬，现在也是在慢慢的改。

谭
访谈人

那像语气这块，你现在是采取什么方式改进吗，是跟其他人沟通不？

张
张洁

AI吧，开始的时候是AI搜改进意见的，但是我感觉AI给的反馈并不能解决，现在的话就是看蜜蜜是怎么沟通的，有时候会加一些语气词，或者表情包。

谭
访谈人

近期有客户反馈，我们在一些问题上的回复比较慢，这个你是怎么看待的呢？

张
张洁

这个大部分的时候就是我没有看到，所以没有及时回复，像下班了就比较少看工作的信息，可能就是错过了。上班的时候有时候在设计，就没有马上看到信息回，如果看到了我就会马上回复客户的。

谭
访谈人

那除了对外的客户沟通，你觉得内部的沟通会有不太顺畅的地方吗，觉得有什么可以解决的方法呢？

张
张洁

内部的沟通的话，可能是跟海武哥的沟通会有一些不顺畅，像有时候客户提了一些需求但是对开发来说是没有必要的，他就会一直采取反驳的态度，但是我从设计上觉得还是需要跟客户一致实现，就会坚持我的想法，如果沟通不下来的话可能就会跟敬和或者杨总说，他们出面来解决。

谭
访谈人

了解的。那当前的工作状态，你觉得可以怎么评价呢？

张
张洁

我觉得现在的状态对我来说是比较舒适自在的，因为跟大家都比较熟悉了，不需要在工作流程和任务上有比较多额外的费时费力沟通。

谭
访谈人

那对公司的薪资福利部分，有觉得需要改进的地方吗？

张
张洁

暂时还没有的。

谭
访谈人

2026年的工作也快进入尾声了，你觉得这一年的工作压力会大吗？

魏
魏大龙

整体还好的，最近就是界画的内容有比较多需要调整的地方，所以会耗时比较多，压力这个暂时没有很大的压力，更多的是在尝试的阶段。

谭
访谈人

这个尝试的阶段主要是指哪些呢？

魏
魏大龙

像扁联这个展览最开始我是做了一版gif的效果图，后来镜宇哥在开发的过程发现有问题，就给了我一些新的方向去调整，最近的两个展览我们也在陆续的发现问题，改进，再测试，有问题再新调整。

谭
访谈人

那这个改进的沟通，你们是怎么协调呢，你觉得这种多次的改进会影响你的自信心吗？

魏
魏大龙

因为镜宇哥是主导开发的，像效果的实现我会听他的多一些，有时候他会给我一个链接，告诉我可以尝试使用哪个效果，我就根据他的链接重新学习再调整，大部分时候我们都会一起沟通这个效果的，有问题了再协商调整就好。这个我觉得是个学习的过程，也挺好的，像之前AE用的比较少，最近也重新开始掌握起来了，也是技能提升的方式。

谭
访谈人

像对外部客户的沟通，你会觉得有压力吗，目前主要是线上为主，如果后期需要线下去做汇报，你觉得有困难不？

魏
魏大龙

线上的沟通不会有压力，基本上就是先把资料整理好给客户看，如果有需要他们决定的话再请他们确定，另外就是他们提问及时回答就好了。如果要线下的话，可能一个人直接面对沟通的话会比较紧张，怕讲不好，不过我觉得可以尝试的。

谭
访谈人

如果要线下开展汇报的话，肯定是一个过程的，前期会有敬和或者其他人在一同协助，后期再慢慢独立担起来的。另外就是，你觉得这一年，你的个人能力有提升不，有达到你入职时想要达成的期望吗？

魏
魏大龙

我觉得个人的能力提升来说，还是有进步的，比起入职的时候掌握的东西，现在在UI上会更加的专业一些，但是还需要继续努力。

谭
访谈人

那像公司的薪资福利这块，你有建议或者意见吗？

魏
魏大龙

我觉得福利都挺好的，意见的话就是希望后期我能达到加薪的标准时，能有加薪的机会。

谭
访谈人

从年后回来开始接受UI的工作大半年了，整体的工作感觉怎样呢？

巫
巫婷婷

从年后回来的话也是陆续的完成了好几个项目，从最开始跟大龙合作的校园项目、阿克苏项目、再到全程主导的古建院预约项目，到现在新昌的项目，也是有了解到了好几种不同的产品类型，在UI技能上也有比较大的提升。

谭
访谈人

那在项目实施的过程中会有压力不，主要是来源于哪些方面？

巫
巫婷婷

压力肯定会有的，但是也在接受的范围内。像最开始的时候跟用户沟通，会害怕自己讲不清楚或者讲不好，像线上汇报的时候，有时候讲完了再等待用户反馈的过程也会比较紧张，怕他们会提出一些自己不太清楚的事情，到现在汇报或者对外沟通的次数多了，心态也渐渐放松下来，心理暗示自己认真听和记，不清楚的多问一遍就好。

谭
访谈人

会遇到需求反复修改的情况不，一般是来自内部还是外部的反复修改需求多，这种情况是怎样解决呢？

巫
巫婷婷

这类的反复修改外部的会多一些，像预约这个项目涉及到三个景区，有时候用户没法做到统一需求，遇到这种情况的话首先会衡量我自己能不能解决，如果可以的话就我自己或者加上开发一起把需求改掉就好；但是像一些比较大的需求变动，我就需要请敬和这边来决定再落实。

谭
访谈人

像内部沟通呢，你觉得会有压力不，之前多次看到你跟海武哥这边的沟通僵持不下，最后你还是情绪很稳定的推进下去，能倾听你的想法不？

巫
巫婷婷

一开始我也是怀疑自我的，觉得是不是我需求没有讲清楚，所以一直被否定，但是任务交给了我，我还是有责任和义务要把事情推进下去的，不能把事情卡在我这，也不应该所有事都让敬和出面去解决，所以就耐着性子再一遍跟海武哥讲，如果还是不行我就跟他说我和用户再确认一下，最后就拿着用户的反馈给海武哥看，把事情落实下来了。对于他可能有时候情绪会比较激动，我觉得站在海武哥的角度也能理解，然后觉得不太好听的话就自动过滤就好，不要因为情绪影响了工作。

谭
访谈人

你觉得从入职到现在，你最大的收获是什么呢？

巫
巫婷婷

我觉得应该是和用户沟通的能力吧，最开始我不知道要怎么沟通才合适，到现在基本上用户提了问题我都能及时的回复他们，或者不清楚的时候先问其他同事，得到反馈再给用户解答；另外就是上次独自出差就讲汇报，开始也是很紧张的，后面敬和说正常工作汇报就好，系统我也是熟悉的，客户的提问清楚的就回答，把握不了的就记录下来回头解决，事情结束之后，我觉得自己还是进步了很多。

谭
访谈人

像后期工作安排，如果给到你像线上展览这类的新任务，你可以接受吗？

巫
巫婷婷

我还是希望可以尝试的，多做一些不一样的项目，也提升自己。

谭
访谈人

你觉得现在公司的氛围怎样，会希望有多一些改变不（像团建之类的活动）？

巫
巫婷婷

我觉得挺好的，虽然说气氛比较安静，但是可以静下心来认真工作。对于活动的话，我觉得团建也挺好的，上一年去景德镇印象还很深刻。

谭
访谈人

最后的问题，你对于目前公司的薪资福利这块满意吗？

巫
巫婷婷

我觉得福利还好的，就是希望可以得到加薪。
